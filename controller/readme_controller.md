#  Controller Pipeline (Оркестратор распознавания)

Модуль оркестрации для связывания потока данных от трекера (YOLO/ByteTrack) с мультимодальной нейросетью (VLM).

Главная задача контроллера — **не верить нейросети на слово с одного кадра**. Модуль накапливает историю детекций для каждого уникального объекта (ценника), проводит мажоритарное голосование для исключения галлюцинаций LLM и вычисляет уровень уверенности (`Confidence Score`) в финальном результате.

##  Структура модуля

* **`controller_main.py`** — Точка входа. Содержит функцию `run_pipeline` для запуска конвейера.
* **`test_logic.py`** — Синтетические интеграционные тесты для проверки логики голосования и таймаутов.
* **`dto/`**
    * `tracker_out.py` — Data Transfer Objects. Содержит датакласс `TrackedCrop` (единый стандарт обмена данными между трекером и оркестратором).
* **`modules/`**
    * `controller.py` — Главный класс `ControllerPipeline`. Управляет бесконечным циклом обработки кадров и перехватывает ошибки VLM.
    * `state_manager.py` — Модуль памяти (`StateManager`). Хранит "активные" треки, считает успешные распознавания и отслеживает пропавшие объекты по таймауту.
    * `results_aggregator.py` — Модуль аналитики (`Aggregator`). Выполняет склейку JSON-ответов с разных кадров и оценивает надежность данных.
    * `detector_adapter.py` — Адаптер для боевого трекера (преобразует сырые боксы YOLO в объекты `TrackedCrop`).
    * `fake_crop_gen.py` — Фейковый генератор данных для тестирования логики без подключения тяжелых моделей.

##  Логика работы конвейера

1. **Получение кадра:** Оркестратор запрашивает следующий `TrackedCrop` у трекера.
2. **Фильтрация:** Если `track_id` уже имеет статус `DONE` (успешно собран) или `DROPPED` (отбракован), кадр игнорируется для экономии ресурсов GPU/API.
3. **Распознавание (Vision):** Кроп отправляется в LLM. Если модель падает с ошибкой или возвращает невалидный JSON, оркестратор перехватывает исключение и продолжает работу.
4. **Накопление (State):** Успешные JSON-ответы складываются во временную память трека. Обновляется счетчик "последний раз видели на кадре X".
5. **Закрытие трека:** * Если трек набрал лимит успешных кадров (например, 3) — он отправляется на агрегацию.
    * Если трек не появлялся в кадре дольше таймаута — он закрывается принудительно (спасаем то, что успели собрать, либо помечаем как `DROPPED`).
6. **Агрегация и Голосование (Vote):** Агрегатор сравнивает значения полей со всех собранных кадров. Побеждает самое частое значение. Присваивается статус `_confidence` (good, uncertain).
7. **Экспорт:** Формируется итоговый Pandas DataFrame со всеми уникальными ценниками.

##  Настраиваемые параметры (Global Config)

Контроллер принимает единый конфигурационный словарь `config_dict`, который позволяет настраивать логику "на лету":

| Параметр | Описание | Значение по умолчанию |
| :--- | :--- | :--- |
| `track_success_threshold` | Целевое количество успешных распознаваний для досрочного закрытия трека. | `3` |
| `track_timeout_frames` | Таймаут (в кадрах). Если объект не появляется столько кадров, трек закрывается. | `20` |
| `min_matches_required` | Минимальное количество совпадений цен для признания результата стабильным (`good`). | `2` |
| `price_fields_priority` | Приоритет полей цен для оценки уверенности (от главного к запасному). | `["price_card", "price_discount", "price_default"]` |

##  Быстрый старт

```python
from controller_main import run_pipeline
from modules.detector_adapter import YoloToCropAdapter
from vision_module import vision_main

# 1. Задаем правила 
MY_CONFIG = {
    "track_success_threshold": 3,       # необходимо распознаний
    "track_timeout_frames": 25,         # время жизни трека
    "min_matches_required": 2           # минимальное кол-во совпадений
}

# 2. Инициализируем источник данных
tracker = YoloToCropAdapter(video_source="video.mp4")

# 3. Запускаем конвейер
result_df = run_pipeline(
    video_path="video.mp4", 
    tracker_module=tracker, 
    vision_callable=vision_main, 
    config_dict=MY_CONFIG
)

# 4. Сохраняем результат
result_df.to_csv("submission.csv")
