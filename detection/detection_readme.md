# 👁 Detection Module (Модуль трекинга и нарезки)

Модуль отвечает за извлечение потока кадров из видео, детекцию ценников с помощью нейросети (YOLO) и отслеживание их перемещения в кадре (ByteTrack). Результатом работы модуля является очередь нормализованных, вырезанных изображений (кропов), готовых к отправке в мультимодальную LLM.

##  Состав модуля

* **`tracker.py`** — Ядро компьютерного зрения. Содержит класс `YOLOTracker`, который:
    * Читает видеопоток (MP4 или Web-камера).
    * Выполняет инференс модели Ultralytics YOLO.
    * Привязывает к объектам уникальные ID с помощью `supervision.ByteTrack`.
    * Эффективно пропускает кадры (`skip_frames`) без тяжелого декодирования `cv2`.
* **`detector_adapter.py`** (в папке `modules`) — Паттерн "Адаптер". Связующее звено между тяжелым трекером и высокоуровневым Оркестратором.
    * Буферизирует найденные детекции.
    * Безопасно вырезает картинки с отступами (`crop_margin`), не выходя за границы кадра.
    * **Поворачивает кропы** для корректного чтения текста нейросетью (`crop_rotation_angle`).

## ⚙ Основные фичи

1. **Аппаратное ускорение:** Автоматический выбор `cuda`/`cpu`.
2. **Offline-first:** Отключены все телеметрии и автообновления YOLO (`YOLO_OFFLINE=1`). Модуль гарантированно работает в закрытом контуре без доступа к интернету.
3. **Оптимизация чтения:** Использование `cap.grab()` и `cap.retrieve()` позволяет мгновенно "проматывать" пустые кадры, экономя ресурсы CPU при работе с 4K-видео.
4. **Отказоустойчивость:** Адаптер перехватывает ошибки сегментации `cv2` (например, при битых координатах бокса) и просто пропускает дефектный ценник, не роняя весь пайплайн.

##  Настройки (через глобальный `config.yaml`)

Модуль гибко настраивается без изменения исходного кода. Параметры читаются Оркестратором и прокидываются в Адаптер:

| Блок | Параметр | Описание | Дефолт |
| :--- | :--- | :--- | :--- |
| `tracker` | `conf` | Порог уверенности YOLO (Confidence). | `0.40` |
| `tracker` | `iou` | Порог пересечения боксов (NMS IOU). | `0.45` |
| `tracker` | `imgsz` | Размер картинки для инференса YOLO. | `640` |
| `tracker` | `skip_frames` | Пропуск N кадров для ускорения пайплайна (e.g. 6 = каждый 7й). | `0` |
| `adapter` | `crop_margin` | Отступ в пикселях (чтобы текст не был прижат к краям). | `15` |
| `adapter` | `crop_rotation_angle` | Угол поворота для вертикальных видео (90, 180, 270). | `90` |
